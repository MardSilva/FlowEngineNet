Evidence, Not Promises

The experiment is successful only when different presentations preserve the same IDs, anchors, and canonical hash.

var hash = integrity.ComputeHash(document);
Console.WriteLine(hash.Hash);

Change presentation, and the hash stays fixed. Change content, and the hash changes. That is a claim the test suite can falsify.
