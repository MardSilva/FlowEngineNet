# Roadmap

## 0.1

- Canonical document model, validation, stable anchors, and hashing
- Typography, reader overrides, and renderer safety constraints
- Renderer-independent adaptive Flow layout
- Standalone HTML renderer
- Sample book and reference CLI
- Local canonical-signature proof of concept
- Security-bounded EPUB import prototype
- Conformance profile 001–012 and Windows/Linux CI

## 0.2

- Experimental pagination
- More EPUB interoperability

## 0.3

- Signature transport and trust experiments
- Provenance
- PDF rendering experiment

## 0.4

- Windows Reader reference application

No release dates are promised. Each milestone depends on evidence from the preceding research. Flow 0.1 publishes no packages and makes no compatibility or standards-conformance guarantee.
